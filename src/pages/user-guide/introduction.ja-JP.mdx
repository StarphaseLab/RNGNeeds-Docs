## RNGNeeds とは？
RNGNeeds は、あらゆる値、型、またはカスタムオブジェクトの確率リストを Unity Inspector 内で直接デザイン・管理できる強力なプラグインです。このプラグインを使用すると、ダイスロール、モンスタースポーン、カードデッキ、アイテムドロップ、ダメージ修正、さらには有機的なアニメーションまで、確率分布を使って比類ない簡単さと使いやすさでコントロールできます。Inspector 上でリスト、ピック数の変数、シードをデザインしたい場合でも、強力な API を使ってコードですべてを制御したい場合でも、RNGNeeds はすべての用途に対応しています。

RNGNeeds は強力なツールであるだけでなく、ユーザーフレンドリーで適応性の高いソリューションでもあります。Inspector からアクセスできるすべての機能と使いやすい API により、コーダーとデザイナーの両方に対応するよう設計されています。このプラグインはすべての LTS バージョンの Unity をサポートし、幅広い強力な機能を提供します。純粋なランダム選択を含むさまざまな確率手法を使用して、一度に複数のアイテムを選択できます。また、優先シードを保持したり、カスタムシードを設定したり、独自の Seed Provider を実装したりする簡単な方法も提供します。さらに、カスタムの Selection Method やシードオプションを簡単に実装・登録できます。

RNGNeeds は、ワークフローをより効率的で適応性の高いものにするのにも役立ちます。外部要因に基づいて確率を動的に変更する Influence Provider を設計できます。固定のピック数を選択するか、バイアスを制御するための調整可能なカーブを持つランダムな範囲を選択することができます。さらに、複数の連続選択防止テクニックにより、連続したアイテム選択を避け、各リストの以前のアイテム選択を追跡して、確定的な確率動作を模倣するための履歴を活用できます。

私たちの取り組みは、現在のバージョンの RNGNeeds にとどまりません。ロードマップには、確率の動的変更、カードデッキの拡張、リスト内のアイテムにユニットを割り当てて選択によってそれらを消費できるようにする機能など、現在積極的に開発中の新しい機能が多数あります。

RNGNeeds をお選びいただき、誠にありがとうございます。私たちは、このプラグインを使って生み出される素晴らしい作品を楽しみにしています。皆様の信頼が、RNGNeeds をすべてのランダムなニーズに対して — おそらく — 最良のソリューションであり続けるよう、開発・改良し続ける私たちの情熱の糧となっています！
