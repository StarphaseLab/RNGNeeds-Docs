# 偏好设置

在 RNGNeeds 插件的"Preferences"部分，您可以自由调整与工具的交互方式。这些选项允许您在紧凑按钮和完整按钮显示之间进行选择、反转滚动方向以获得更自然的操作感等。此外，您还可以根据编辑器的主题（深色或浅色）设置视觉偏好。一切都是为了让您的体验尽可能地人性化，让您能够专注于为游戏元素精心设计概率列表。{{ className: 'lead' }}

### 了解 RNGNeeds 偏好设置

RNGNeeds 包含三种类型的偏好设置。

- **Global Preferences**（全局偏好）- 这些选项在所有抽屉之间共享，定义其高级行为，例如选项级别、滚动方向、渐变着色或日志记录器设置。
- **Default Drawer Settings**（默认抽屉设置）- 这些偏好是针对特定抽屉的，并在每个新抽屉首次初始化（查看）时应用。如果您发现自己每次都要为新抽屉更改相同的设置，这个功能非常实用。只需在 Preferences 窗口的 **Drawer Options &raquo; Default Drawer Settings** 下更改默认值即可。
- **Color Palettes**（颜色调色板）- 所有抽屉共享的颜色主题列表。调色板不会直接应用于抽屉，抽屉仅保留对调色板名称的引用。这样您可以自定义现有调色板，抽屉将自动反映更改。

## Preferences 窗口

RNGNeeds 偏好设置位于 Unity 项目中其他 Editor 偏好设置旁边。要打开偏好设置窗口，请前往 **Editor Menu Bar &raquo; Edit &raquo; Preferences &raquo; RNGNeeds**。

  <Col>

      **Drawer Option Buttons** - 在抽屉标题中显示 Full、Compact 或 Informative 按钮。如果 Inspector 空间有限，请使用 Compact 模式。Informative 模式（推荐）将直接在按钮内显示设置。

## 持久化抽屉设置

RNGNeeds 静默地单独追踪每个抽屉的偏好设置，让您在处理大量设计对象时保持井然有序。通过这种方式，您可以在设计 Probability Lists 时轻松更改抽屉的外观，之后再回来时设置保持不变。所有选项应随您的提交和版本控制一起保留。

<Note>
    偏好设置窗口提供将所有偏好重置为默认值的选项，这也会重置默认抽屉设置。<br/>
    偏好设置存储在项目文件夹的 **\/ProjectSettings\/RNGNeedsSettings.asset** 下。<br/>
    此文件的更改将频繁出现在您的版本控制中。这是设计如此，以确保您的所有设置在工作时得到保留。<br/>
    如果您不想提交 RNGNeeds 的偏好设置，请将以下内容添加到您的 `.gitignore` 文件中：
    ```
    # Ignore RNGNeedsSettings Asset
    /[Pp]roject[Ss]ettings/RNGNeedsSettings.*
    ```
</Note>
