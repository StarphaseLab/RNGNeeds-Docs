## 安装

**1. 打开 Unity Editor**<br/>
首先打开您的 Unity Editor。确保您已打开一个项目，或者在必要时创建一个新项目。<br/><br/>
**2. 访问 Unity Asset Store**<br/>
在 Unity Editor 内导航至 Unity Asset Store。您可以通过点击菜单栏中的 **Window**，然后从下拉菜单中选择 **Asset Store** 来完成此操作。<br/><br/>
**3. 搜索 RNGNeeds**<br/>
在 Asset Store 的搜索栏中输入"RNGNeeds"并按 Enter。RNGNeeds 插件应会出现在搜索结果中。<br/><br/>
**4. 下载并导入插件**<br/>
从搜索结果中点击 RNGNeeds 插件以打开其页面。
在此，点击 **Download** 或 **Import** 按钮（按钮的标签将取决于您之前是否已下载过该插件）。
如果出现要求升级的窗口，只需点击 Continue 即可。<br/><br/>
下载完成后，Unity 将自动提示您将插件导入到项目中。
确保 Import Unity Package 窗口中所有文件均已勾选，然后点击 Import。<br/><br/>

## 快速开始

要在您的项目中开始使用概率分布，请将泛型 `ProbabilityList<T>` 类添加到您的某个类中，或者通过在 Project 面板中右键单击并选择 **Create &raquo; C# Script** 来创建一个新脚本。

<Note>
    您可以在任何 `MonoBehaviour` 或 `ScriptableObject` 类中使用多个 **ProbabilityList**，并使用 Inspector 设计概率分布。
    您也可以在任何其他类中使用它，并通过 API 控制列表及其概率分布。
</Note>

在本示例中，我们将创建一个更频繁地掷出六点的有偏骰子。将脚本命名为 `Die` 并打开它。<br/>
继承自 `ScriptableObject` 并添加一个 `int` 类型的 Probability List。

```csharp {{ title: 'Adding the ProbabilityList'}}
using UnityEngine;
using RNGNeeds;

[CreateAssetMenu(fileName = "dXX", menuName = "My Die")]
public class Die : ScriptableObject
{
    public ProbabilityList<int> die;
}
```

在 Unity Editor 中，右键单击 **Assets** 文件夹并选择 **Create &raquo; My Die**。
这将创建一个建议名称为 `dXX` 的新 Scriptable Object。我们将创建一个六面骰子，因此将对象命名为 `D6 Die`。
点击该对象将在 Inspector 中显示其属性，您将在那里看到 Probability List Drawer。

<ImageX className="w-full h-auto" src={exampleEmptyList} alt="Empty ProbabilityList" width={1000} />

要向列表中添加项目，请点击右侧的 `Add` 按钮。这些项目将代表骰子的各个面。添加六个面并指定它们的值。

<ImageX className="w-full h-auto" src={exampleAddedSides} alt="ProbabilityList with items" width={1000} />

目前，各项目的概率是均等的。我们想让骰子更频繁地掷出六点，但保留其他面之间的均等概率。

<Note>
    您可以通过在条带上拖动矩形或其边缘来调整项目概率，也可以直接输入数值。直接输入将根据各项目的分布比例重新计算其他项目的概率。
</Note>

点击"第 6 面"的概率 `16.67%`，输入 `0.2`（即 20%），然后按 `Enter`。其他项目的概率将降至 16%。

<ImageX className="w-full h-auto" src={exampleDirectInput} alt="Direct Input" width={1000} />

现在是掷骰子的时候了。在 RNGNeeds 中，您可以通过调用 `.PickValue()` 轻松从 ProbabilityList 中选择一个值。让我们通过添加一个返回掷骰结果的函数来使骰子对象变得有用。

```csharp {{ title: 'Selecting values from list' }}
using UnityEngine;
using RNGNeeds;

[CreateAssetMenu(fileName = "DXX", menuName = "My Die")]
public class Die : ScriptableObject
{
    public ProbabilityList<int> die;
    
    public int Roll()
    {
        return die.PickValue();
    }
}
```

现在，每当您对某个骰子调用 Roll() 时，您将根据概率分布获得一个 `int` 值。
<Note>
    使用这种方法，您现在可以为您的项目创建多个骰子，例如 `d10` 或 `d20`，并轻松掷骰。每个 Die ScriptableObject 都可以拥有自己的项目数量（骰子面数）和概率分布。
    说到这里，现在是将我们的六面骰子重命名为 `D6 Die (biased)` 的好时机。
</Note>
