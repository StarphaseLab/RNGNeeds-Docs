## RNGNeeds 是什么？
RNGNeeds 是一款功能强大的插件，让您能够直接在 Unity Inspector 中为任意值、类型或自定义对象设计和管理概率列表。借助这款插件，您可以轻松掌控骰子投掷、怪物生成、卡牌牌组、道具掉落、伤害修正，甚至有机动画——以概率分布为基础，兼具无与伦比的简洁性与易用性。无论您是想直接在 Inspector 中设计列表、可变抽取数量和种子，还是希望通过强大的 API 以代码全面掌控一切，RNGNeeds 都能满足您的需求。

RNGNeeds 不仅是一款强大的工具，更是一套易于上手、灵活可扩展的解决方案。它兼顾程序员与设计师的需求，所有功能均可通过 Inspector 访问，同时提供简洁易用的 API。该插件支持所有 Unity LTS 版本，并提供一系列强大特性：您可以使用多种概率方法一次抽取多个项目，包括纯随机选取；轻松保留偏好种子、设置自定义种子，或实现您自己的 Seed Provider；此外，还可以方便地实现并注册自定义 Selection Methods 或种子选项。

### 为什么使用 RNGNeeds？
因为游戏中的随机性很少只是“随机”本身。它很快就会关系到 **节奏**、**平衡**、**多样性**，以及整体的 **玩家体验**。

RNGNeeds 提供了一种结构清晰、对设计师友好的方式来塑造这种体验，同时又不会在项目成长过程中失去灵活性。它让您更容易在 Inspector 中进行可视化编辑，尝试不同的选择方式，避免不必要的重复，并构建能够自然响应游戏状态变化的系统。它还可以通过 **PLCollection** 这样的可复用分组结构，让更大的配置保持清晰有序，避免概率设计随着项目扩大而变得难以管理。

简而言之，RNGNeeds 适合那些希望概率设计在项目从原型走向更大规模时，依然保持 **有表现力**、**易于管理**、并且 **切实可用** 的团队和项目。

RNGNeeds 还能帮助您打造更高效、更灵活的工作流。您可以设计 Influence Providers，根据外部因素动态调整概率；选择固定的抽取数量，或通过可调曲线在随机范围内控制偏向；利用多种重复防止技术避免连续选中同一项目；并为每个列表单独追踪历史抽取记录，以模拟确定性概率行为。

我们对 RNGNeeds 的承诺不止于当前版本。我们很高兴地告诉您，路线图上已有一系列新功能正在积极开发中，包括概率的动态修改、卡牌牌组扩展，以及为列表中的项目分配数量并允许抽取消耗等功能。
