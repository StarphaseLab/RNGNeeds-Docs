# ProbabilityList&lt;T&gt;

RNGNeeds をトップダウンで学習している場合は、まず <a href={GuidePLCollection.Link}>ガイド</a> と概念ドキュメントを参照し、メインのリスト型の正確なランタイム構造を確認したい場合にこちらに戻ってきてください。 {{ className: 'lead' }}

`ProbabilityList<T>` は RNGNeeds のコアとなるランタイム型です。

`ProbabilityItem<T>` エントリのリストを格納し、以下の API を提供します。

- アイテムの追加と削除
- 確率とウェイトの管理
- 1 つまたは複数の値のピック
- 繰り返しの防止
- シードとピック履歴の操作
- 消耗リストのサポート
- インフルエンスプロバイダーの接続

---

## 重要な概念

<Note>
  <p><strong>基本確率と評価済み確率の違い。</strong></p>
  <p><code>GetItemBaseProbability(...)</code> は保存されたベースライン値を返します。<code>GetItemProbability(...)</code> は、インフルエンスを含む、選択時に実際に使用される有効な確率を返します。</p>
</Note>

<Note>
  <p><strong>ロックと無効化は異なります。</strong></p>
  <p>無効化されたアイテムは選択時に無視されます。ロックされたアイテムはピックされる可能性がありますが、一部のリスト操作ではその確率が再配分されません。</p>
</Note>

<Note>
  <p><strong>一部のピックメソッドは共有リストを返します。</strong></p>
  <p><code>LastPickedValues</code> などのプロパティや共有リストを返すメソッドは、余分なアロケーションを避けるよう最適化されています。安定した所有権が必要な場合は、データを自分のリストにコピーしてください。</p>
</Note>

## 基本的なワークフロー

```csharp
var lootTable = new ProbabilityList<string>();

lootTable.AddItem("Potion", 0.5f);
lootTable.AddItem("Gold", 0.3f);
lootTable.AddItem("Rare Gem", 0.2f);

string reward = lootTable.PickValue();
```

## 選択の動作

  </Member>
  <Member kind="PROPERTY" color="sky" name="ShuffleIterations" signature="int">
    <code>PreventRepeatMethod.Shuffle</code> が使用するシャッフルパスの回数です。1 から 5 の間にクランプされます。
  </Member>
  <Member kind="PROPERTY" color="sky" name="PickCountMin" signature="int">
    マルチピックメソッドが選択する値の最小数です。
  </Member>
  <Member kind="PROPERTY" color="sky" name="PickCountMax" signature="int">
    マルチピックメソッドが選択する値の最大数です。
  </Member>
  <Member kind="PROPERTY" color="sky" name="LinkPickCounts" signature="bool">
    true の場合、有効なピック数は <code>PickCountMin</code> に固定されます。
  </Member>
  <Member kind="PROPERTY" color="sky" name="MaintainPickCountIfDisabled" signature="bool">
    無効なアイテムが干渉する場合でも、目的のピック数に達しようとし続けます。これにより結果の分布が変わる可能性があり、病的なケースに対する組み込みのフェイルセーフチェックがあります。
  </Member>
  <Member kind="PROPERTY" color="sky" name="PickCountCurve" signature="AnimationCurve">
    ピック数が最小値と最大値の間でランダムに選択される際に使用するバイアスを制御します。
  </Member>
</MemberGroup>
