## API 结构一览

以下是最简洁的 API 结构图：首先是你最可能直接使用的核心运行时类型，其次是当你需要自定义或扩展 RNGNeeds 时会用到的扩展点。

### 核心运行时类型

这些是日常运行时使用的主要构建块——在创建列表、处理条目、组织列表组或查看最近抽取记录时，你通常会首先接触这些类型。

<LinkGrid>
    <LinkCard href={API_ProbabilityList.Link} title={API_ProbabilityList.Title}>
        主要的运行时类型。从这里开始了解列表的创建、条目的添加、值的抽取、概率与权重的管理、种子设置、耗尽机制、历史记录以及重复防止功能。
    </LinkCard>
    <LinkCard href={API_ProbabilityItem.Link} title={API_ProbabilityItem.Title}>
        单个条目层。当你需要了解启用与锁定条目、影响值、权重、单位、耗尽机制，以及条目有效概率的评估方式时，请查阅此页。
    </LinkCard>
    <LinkCard href={API_PLCollection.Link} title={API_PLCollection.Title}>
        用于同时处理多个具名或有索引的概率列表的集合层。非常适合分组战利品表、对话池、遭遇集合及类似系统。
    </LinkCard>
    <LinkCard href={API_PickHistory.Link} title={API_PickHistory.Title}>
        最近抽取记录的历史辅助工具。当你需要查看已选内容、实现重复防止逻辑或处理近期抽取结果时，非常有用。
    </LinkCard>
</LinkGrid>

这些页面适用于高级集成工作——自定义选择行为、确定性工作流、种子控制，以及将这些系统关联起来的静态注册表。

<LinkGrid>
    <LinkCard href={API_SelectionMethods.Link} title={API_SelectionMethods.Title}>

## 深入之前的几个重要概念

<Note>
    <p><strong>基础概率</strong>不一定等于选择时实际使用的最终概率。</p>
    <p><code>ProbabilityItem&lt;T&gt;</code> 存储的是 <code>BaseProbability</code>，但经过评估后的 <code>Probability</code> 可能因影响提供者、分布设置及其他运行时状态而发生变化。</p>
</Note>

<Note>
    <p><strong>Enabled</strong> 与 <strong>Locked</strong> 含义不同。</p>
    <p>禁用的条目在选择时会被忽略。锁定的条目仍可被选中，但其概率受到保护，不会受到规范化和重新分配等列表操作的影响。</p>
</Note>

<Note>
    <p><strong>精选文档与 API 文档的职责不同。</strong></p>
    <p>如果你需要教程、示例和设计建议，精选章节才是正确的去处——尤其是 <a href={DocsOverviewPage.Link}>文档概览</a>、<a href={ProbabilityInfluencePage.Link}>{ProbabilityInfluencePage.Title}</a>、<a href={SeedingOptionsPage.Link}>{SeedingOptionsPage.Title}</a> 以及 <a href={NestingListsPage.Link}>{NestingListsPage.Title}</a>。</p>
</Note>
