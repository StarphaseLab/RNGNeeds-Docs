# ProbabilityList&lt;T&gt;

If you are learning RNGNeeds from the top down, start with the <a href={GuidePLCollection.Link}>guides</a> and conceptual docs first, then come back here when you want the exact runtime shape of the main list type. {{ className: 'lead' }}

`ProbabilityList<T>` is the core runtime type in RNGNeeds.

It stores a list of `ProbabilityItem<T>` entries and provides the APIs for:

- adding and removing items
- managing probabilities and weights
- picking one or many values
- preventing repeats
- working with seeds and pick history
- supporting depletable lists
- connecting influence providers

---

## Important concepts first

<Note>
  <p><strong>Base probability vs evaluated probability.</strong></p>
  <p><code>GetItemBaseProbability(...)</code> returns the stored baseline. <code>GetItemProbability(...)</code> returns the effective probability currently used during selection, including influence.</p>
</Note>

<Note>
  <p><strong>Locked is not the same as disabled.</strong></p>
  <p>Disabled items are ignored during selection. Locked items can still be picked, but certain list operations will not redistribute their probability.</p>
</Note>

<Note>
  <p><strong>Some pick methods return shared lists.</strong></p>
  <p>Properties like <code>LastPickedValues</code> and methods returning shared lists are optimized to avoid extra allocations. If you need stable ownership, copy the data into your own list.</p>
</Note>

## Common workflow

```csharp
var lootTable = new ProbabilityList<string>();

lootTable.AddItem("Potion", 0.5f);
lootTable.AddItem("Gold", 0.3f);
lootTable.AddItem("Rare Gem", 0.2f);

string reward = lootTable.PickValue();
```

## Selection behavior

<MemberGroup title="Selection settings" tone="amber">
  <Member kind="PROPERTY" color="sky" name="SelectionMethodID" signature="string">
    Identifier of the selection method used by this list. The identifier is resolved through <a href={API_RNGNeeds.Link}>{API_RNGNeeds.Title}</a>.
  </Member>
  <Member kind="PROPERTY" color="sky" name="PreventRepeat" signature="PreventRepeatMethod">
    Controls how repeated picks are handled.
  </Member>
  <Member kind="PROPERTY" color="sky" name="ShuffleIterations" signature="int">
    Number of shuffle passes used by <code>PreventRepeatMethod.Shuffle</code>. Clamped between 1 and 5.
  </Member>
  <Member kind="PROPERTY" color="sky" name="PickCountMin" signature="int">
    Minimum number of values selected by multi-pick methods.
  </Member>
  <Member kind="PROPERTY" color="sky" name="PickCountMax" signature="int">
    Maximum number of values selected by multi-pick methods.
  </Member>
  <Member kind="PROPERTY" color="sky" name="LinkPickCounts" signature="bool">
    When true, the effective pick count is fixed to <code>PickCountMin</code>.
  </Member>
  <Member kind="PROPERTY" color="sky" name="MaintainPickCountIfDisabled" signature="bool">
    Keeps trying to reach the desired pick count even when disabled items interfere. This can change the resulting distribution and has built-in fail-safe checks for pathological cases.
  </Member>
  <Member kind="PROPERTY" color="sky" name="PickCountCurve" signature="AnimationCurve">
    Controls the bias used when the pick count is randomly chosen between min and max.
  </Member>
</MemberGroup>
