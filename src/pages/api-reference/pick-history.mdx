# PickHistory

`PickHistory` stores recent picks made by a `ProbabilityList<T>`.

Each history entry records:

- the picked item index
- the time of the pick

The history is used by convenience properties such as `LastPickedIndex`, `LastPickedValues`, and similar helpers on `ProbabilityList<T>`.

## Core members

<MemberGroup title="History access" tone="sky">
  <Member kind="PROPERTY" color="sky" name="History" signature="List<HistoryEntry>">
    The underlying list of history entries.
  </Member>
  <Member kind="PROPERTY" color="sky" name="Capacity" signature="int">
    Maximum number of entries to retain. Minimum value is 1.
  </Member>
  <Member kind="PROPERTY" color="sky" name="LatestIndex" signature="int">
    Index of the most recent pick, or <code>-1</code> if history is empty.
  </Member>
  <Member kind="PROPERTY" color="sky" name="LatestEntry" signature="HistoryEntry">
    The most recent history entry, or <code>null</code> when history is empty.
  </Member>
</MemberGroup>

<Note>
  <p><strong>Some retrieval helpers return shared lists.</strong></p>
  <p>That avoids extra allocations. If you need a stable copy, pass in your own list and fill that instead.</p>
</Note>

<Note>
  <p><strong>History entries are pooled.</strong></p>
  <p>RNGNeeds reuses <code>HistoryEntry</code> objects to reduce garbage creation. You can pre-warm the pool via <code>RNGNeedsCore.WarmupHistoryEntries(...)</code> if needed.</p>
</Note>
