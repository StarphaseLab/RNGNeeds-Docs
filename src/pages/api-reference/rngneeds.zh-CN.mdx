# RNGNeedsCore

`RNGNeedsCore` 是 RNGNeeds 的静态集成与扩展入口点。当你需要自定义包级别的行为时使用它，例如注册选择方法、配置种子提供者、控制日志输出或其他全局集成点。对于日常的列表创建和值的抽取，请从 <a href="/api-reference/probability-list">ProbabilityList&lt;T&gt;</a> 开始。{{ className: 'lead' }}

## 何时使用此类型

在以下情况下使用 `RNGNeedsCore`：

- 注册自定义 `ISelectionMethod`
- 检查可用选择方法的列表
- 替换全局种子提供者
- 将种子提供者重置为默认行为
- 为对内存分配敏感的场景预热历史条目对象池
- 在调试时控制 RNGNeeds 的日志详细程度

## 选择方法

`RNGNeedsCore` 的这一部分负责发现、注册和解析选择方法。

<MemberGroup title="Selection method members" tone="amber">
  <Member kind="PROPERTY" color="sky" name="RegisteredSelectionMethods" signature="List<(string Identifier, string Name)>">
    以标识符/名称对的形式返回当前已注册的选择方法。当你需要在运行时检查可用方法，或构建自定义方法选择 UI 时，此属性非常有用。
  </Member>
  <Member kind="PROPERTY" color="sky" name="DefaultSelectionMethodID" signature="string">
    返回在找不到有效方法时所使用的后备选择方法的标识符。
  </Member>
  <Member kind="METHOD" color="emerald" name="RegisterSelectionMethod" signature="void RegisterSelectionMethod(ISelectionMethod selectionMethod)">
    注册一个自定义选择方法。该方法必须公开一个非空的唯一 <code>Identifier</code>。
  </Member>
  <Member kind="METHOD" color="emerald" name="GetSelectionMethod" signature="ISelectionMethod GetSelectionMethod(string identifier)">
    通过标识符获取已注册的选择方法。如果标识符未知，RNGNeeds 将回退到默认选择方法。
  </Member>
</MemberGroup>

### 为什么 `Identifier` 很重要

选择方法标识符是 RNGNeeds 用于查找方法的稳定字符串键。

这意味着它在以下几个地方都至关重要：

- 当你注册自定义方法时
- 当 `ProbabilityList<T>.SelectionMethodID` 存储所选方法时
- 当序列化数据需要在之后解析正确的方法时
- 当 RNGNeeds 因标识符无效或已不再注册而回退时

```csharp
public class MySelectionMethod : SelectionMethodBase
{
    public override string Identifier => "MyCustomMethod";
    public override string Name => "My Custom Method";

    protected override bool SelectItem(out int selectedIndex)
    {
        // Your custom selection logic here.
    }
}

RNGNeedsCore.RegisterSelectionMethod(new MySelectionMethod());
```

## 行为说明

<Note>
  <p><strong>回退行为是有意为之的。</strong></p>
  <p>如果请求的选择方法标识符无法被解析，<code>GetSelectionMethod(...)</code> 会返回后备方法，而不是抛出异常。这有助于在自定义方法丢失或被重命名时，仍能保持序列化资产可用。</p>
</Note>

<Note>
  <p><strong>自定义方法必须使用唯一标识符。</strong></p>
  <p>如果你尝试注册第二个具有相同标识符的方法，RNGNeeds 会记录一条警告并保留已有的方法。</p>
</Note>
