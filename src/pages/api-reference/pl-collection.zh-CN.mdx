# PLCollection&lt;T&gt;

想先看实操教程？从 <a href={GuidePLCollection.Link}>{GuidePLCollection.Title}</a> 开始，然后将本页作为集合 API 的简明代码参考。{{ className: 'lead' }}

`PLCollection<T>` 将多个 `ProbabilityList<T>` 实例组织到一个集合中。

当一个列表不够用，且你需要一个更高层次的结构来管理命名或索引列表组时，请使用它。

---

## 典型使用场景

- 分组战利品表
- 命名对话池
- 遭遇事件分类
- 多生物群系刷新列表
- 任何需要将多个概率列表归为一组的系统

## 命名访问与索引访问

<Note>
  <p><strong>命名访问通常是更简洁的 API。</strong></p>
  <p>基于索引的访问适用于严格受控的内部系统，但当集合代表内容分组时，基于名称的访问通常更清晰、更易于维护。</p>
</Note>

<Note>
  <p><strong>列表名称比初看起来更重要。</strong></p>
  <p><code>ListName</code> 不仅仅是一个可选的显示标签。它也是让 <code>PLCollection&lt;T&gt;</code> 中的命名查找变得实用的关键——无论是在编辑器工作流中，还是在通过名称检索或抽取列表的代码中。</p>
</Note>

## 示例

```csharp
var responses = new PLCollection<string>();
responses.AddList("Friendly");
responses.AddList("Hostile");

responses.GetList("Friendly")?.AddItems("Hello", "Good to see you", "Welcome back");
responses.GetList("Hostile")?.AddItems("Go away", "Not interested", "Leave me alone");

responses.PickValueFrom("Friendly", out var line);
```
