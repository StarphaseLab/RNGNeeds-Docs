## A few important concepts before you dive in

<Note>
    <p><strong>Base probability</strong> is not always the same as the final probability used during selection.</p>
    <p><code>ProbabilityItem&lt;T&gt;</code> stores a <code>BaseProbability</code>, but the evaluated <code>Probability</code> can change because of influence providers, spread settings, and other runtime state.</p>
</Note>

<Note>
    <p><strong>Enabled</strong> and <strong>Locked</strong> mean different things.</p>
    <p>Disabled items are ignored during selection. Locked items can still be selected, but their probability is protected from certain list operations such as normalization and redistribution.</p>
</Note>
