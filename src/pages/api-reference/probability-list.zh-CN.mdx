# ProbabilityList&lt;T&gt;

如果你正在从头学习 RNGNeeds，建议先阅读<a href={GuidePLCollection.Link}>指南</a>和概念文档，然后在需要了解主列表类型的确切运行时结构时再回到本页。{{ className: 'lead' }}

`ProbabilityList<T>` 是 RNGNeeds 中的核心运行时类型。

它存储一组 `ProbabilityItem<T>` 条目，并提供以下功能的 API：

- 添加和移除项目
- 管理概率和权重
- 选取单个或多个值
- 防止重复选取
- 使用种子和选取历史
- 支持可耗尽列表
- 连接影响提供者

---

## 重要概念

<Note>
  <p><strong>基础概率与计算概率。</strong></p>
  <p><code>GetItemBaseProbability(...)</code> 返回存储的基准值。<code>GetItemProbability(...)</code> 返回当前选取时实际使用的有效概率，包含影响因素。</p>
</Note>

<Note>
  <p><strong>锁定与禁用不同。</strong></p>
  <p>禁用的项目在选取时会被忽略。锁定的项目仍可被选中，但某些列表操作不会重新分配其概率。</p>
</Note>

<Note>
  <p><strong>部分选取方法返回共享列表。</strong></p>
  <p><code>LastPickedValues</code> 等属性以及返回共享列表的方法经过优化，避免额外内存分配。如果需要稳定的数据所有权，请将数据复制到你自己的列表中。</p>
</Note>

---

## 常见用法

```csharp
var lootTable = new ProbabilityList<string>();

lootTable.AddItem("Potion", 0.5f);
lootTable.AddItem("Gold", 0.3f);
lootTable.AddItem("Rare Gem", 0.2f);

string reward = lootTable.PickValue();
```
