## What is Probability Influence?

Simply put, Probability Influence is an **adjustment to the designed probability**.

Let's say you design a 3% chance of dropping a rare item for the player. 
Using probability influence, this chance can be increased or decreased dynamically during gameplay based on external factors. 
For instance, you may want to increase the chance if the player is performing well, or decrease the odds if a rare item was dropped recently. 

Once the logic and rules are set-up by the coder, the game designer can start crafting unique game mechanics.

For the purposes of this guide we will be using item drop rates as a well known game mechanic example. 

### *How does it work?*

The influence is a `float` value between `-1 and 1`, with **zero** meaning there is **no influence**.

<ImageX className="w-full h-auto" src={probabilityInfluenceFloatValue} alt="Probability Influence - Float Value" width="1000"/>

This value is provided to the Probability List by an **Influence Provider**, a script or an object utilizing a special interface. But more on that later.

The influence value (-1 to 1) would not be much useful if there was no control over how much it adjusts individual items in the list. 
Therefore, an **Influence Spread** comes into play as a way for the game designer to fine tune the actual influence over designed probabilities.

Spread maps the influence range onto the actual adjustment of probabilities.

**IMAGE - spread mapped onto a Health Globe Pickup - 20% chance (10% to 50%).**

In the example above, the chance a monster drops a health globe is designed as 20%. 
The game designer wants this chance to be influenced by the amount of player's health to increase the odds of a health globe drop when the player is injured, or decrease if the player is healthy, respectively.

The maximum negative influence (-1) will reduce the probability of the item to 10%, and the maximum positive influence (1) 
will increase the probability to 50%. Any value between -1 and 1 will map onto the spread range proportionally.



Whenever values are selected, the Probability List will first check if any of its items are *influenced*. 
If so, RNGNeeds will calculate the adjusted probabilities based on any influence provided. 
Once this is done, the selection process continues with the adjusted probabilities.

<Note>
    Calculating the influence right before the selection creates a dynamic environment where probabilities are adjusted at runtime based on logic coming from external factors. 
    Take a look at the <a href={ExamplesMonsterSpawnerPage.Link}>{ExamplesMonsterSpawnerPage.Title}</a> sample, where monsters are spawned randomly from three locations based on the player's distance to them.
</Note>



In RNGNeeds, you can define influence by implementing `IProbabilityInfluenceProvider` interface.
An object or class implementing this interface can be assigned to any item in list, and will serve as a provider of the value between -1 and 1, thus becoming an **Influence Provider**. In addition, values themselves
can be influence providers. In this sample, the `SpawnLocation` MonoBehaviour is the provider and the logic and math of the value is defined by the player's distance.

```csharp {{ title: 'Spawn Location Code'}}
public class SpawnLocation : MonoBehaviour, IProbabilityInfluenceProvider
{
    // code not relevant for this guide was omitted
    
    public Transform playerLocation;
    public float DistanceToPlayer => Vector3.Distance(transform.position, playerLocation.position);
    
    public float ProbabilityInfluence => DistanceToPlayer.Remap(0f, 30f, 1f, -1f);
    public string InfluenceInfo => $"Distance to player: {DistanceToPlayer} = {ProbabilityInfluence}";
}
```

In this case, the distance to player is remapped - if the distance is zero, the influence provided will be 1, meaning the maximum positive influence on the probability.
And if the distance reaches 30, influence will be -1, the maximum negative influence.

So how does this simple value actually alter the probability? Entering **Influence Spread** ...

### *What is Influence Spread?*

Spread defines the limits on how much the influence adjusts the probability. Remember the sliders with handles? That's spread, and using the slider, you can define the amount the probability raises or drops for each item individually.
