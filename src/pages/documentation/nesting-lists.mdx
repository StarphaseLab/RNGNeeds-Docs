# Nesting Lists

Nesting multiple Probability Lists within other collections is a powerful tool for organization. 
While it's possible to nest lists within a standard C# List or Array, our specialized class for grouping Probability Lists offers additional benefits. 
These include the ability to name lists within the collection and select values from the entire collection, enhancing both usability and functionality. {{ className: 'lead' }}

<Note>
    This page introduces the features and usage of PLCollection class. Visit the 
    <a href={GuidePLCollectionExample.Link}>{GuidePLCollectionExample.Title}</a> page to see a simple example of how to use PLCollection in practice.
</Note>

## PLCollection Class

The `PLCollection<T>`, short for **Probability List Collection** is a generic class that can hold multiple Probability Lists of the same type `T`. 
The class comes with many useful methods that not only help you manage the lists but also allow you to select values from the whole collection.

PLCollection is also a great help for game designers who can take advantage of the special inspector drawer, which allows them to easily manage and visualize the lists in the Unity Editor.

### Setting up PLCollection

To start organizing your lists, declare a simple `PLCollection<T>` class in one of your **MonoBehaviour** or **ScriptableObject** scripts, 
similar to how you would declare ProbabilityList of your type.

```csharp {{ title: 'Adding PLCollection' }}
using RNGNeeds;

public PLCollection<string> myCollection;
```

<ImageX className="w-full h-auto" src={plCollectionBasicFunctions} alt="PLCollection - Basic Functions" width="1000"/>

In the Unity Editor Inspector, you will see a new section for the `PLCollection`. 
In the top left, the name of your property is displayed along with the number of lists in the collection.
You can start adding lists by clicking the **Add List to Collection** button.

### Naming Lists

Newly created lists will be named automatically by assigning them a number corresponding to their position in the collection.
The format of the name is `#index`, for example, `#0`, `#1`, `#2`, etc. You can rename the lists by clicking on the name field and typing a new one.

<ImageX className="w-full h-auto" src={plCollectionNamingLists} alt="PLCollection - Naming Lists" width="1000"/>

The name itself is stored within the ProbabilityList object and is not a part of the PLCollection class. 
You can set a name for any list, whether it's part of the collection or not, using the `ListName` property.

```csharp
myProbabilityList.ListName = "My List";
```

If you add a list without a name, the PLCollection will set its name automatically.

```csharp {{ title: 'Adding and naming lists via code' }}
// Adding an unnamed list
myCollection.AddList(myList);               // List Name will be '#0'
myCollection.AddList(myList, "My List");    // List Name will be 'My List'

// Adding a named list
myList.ListName = "My List";
myCollection.AddList(myList);               // List Name will not change

// Renaming a list
myCollection.SetListName(0, "My List");
myCollection.SetListName("My List", "New Name");
```

The `SetListName` methods return `true` if the list was found and renamed, and `false` otherwise.

### Reordering Lists

To enable reordering of lists in the inspector, click the **Reorder Lists** button in the top right corner of the collection.
Arrows will appear next to each list, allowing you to move them up or down.

<ImageX className="w-full h-auto" src={plCollectionReorderingLists} alt="PLCollection - Reordering Lists" width="1000"/>

You can also reorder lists programmatically using the `MoveListUp` and `MoveListDown` methods.

```csharp {{ title: 'Reordering lists via code' }}
myCollection.MoveListUp(1);     // Move list at index 1 up
myCollection.MoveListDown(1);   // Move list at index 1 down
```

A list can be moved up or down only if it's not the first or last list in the collection, respectively.
These methods return `true` if the list was moved, and `false` otherwise. 

### Removing Lists

The collection is **Locked** by default, preventing accidental removal of lists. 
You can enable removing of lists by clicking on the **Lock** button in the top right corner of the collection.

<ImageX className="w-full h-auto" src={plCollectionRemovingLists} alt="PLCollection - Removing Lists" width="1000"/>

Once unlocked, red **Remove List from Collection** buttons will appear next to each list, allowing you to delete them.
In addition, you can clear the entire collection by clicking the **Clear Collection** button in the header.

<Note>
    Removing a list or clearing the collection are critical actions, indicated by the red color of the buttons. 
    While these actions do not come with a popup confirmation, they can be undone by using the Unity Editor's Undo feature.
</Note>

```csharp {{ title: 'Removing lists via code' }}
myCollection.RemoveList(1);             // Remove list at index 1
myCollection.RemoveList("My List");     // Remove list with name "My List"
```

The `RemoveList` methods return `true` if the list was found and removed, and `false` otherwise.

### Clearing Lists

PLCollection also provides handy methods for clearing the individual lists (ie. removing all items from the list). 
This can be beneficial when you want to keep the structure of the collection but remove the contents of the lists.
Please note that clearing a list also removes its History. To learn more about History, check the [Pick History](/documentation/pick-history#history-structure) section.

```csharp {{ title: 'Clearing lists via code' }}
myCollection.ClearList(1);              // Clear list at index 1
myCollection.ClearList("My List");      // Clear list with name "My List"
myCollection.ClearAllLists();           // Clear all lists in the collection

myCollection.ClearCollection();         // Removes all lists from the collection
```

The `ClearList` methods return `true` if the list was found and cleared, and `false` otherwise.

## Selecting Values from Collection

To select values from a list in the collection, you can either retrieve the list directly or use the collection's methods.

### Selecting directly from Probability List

You can access a list from the collection by its index or name and then select a value from it as you would with a standard Probability List.

```csharp {{ title: 'Selecting values directly from list' }}
// Retrieving list from collection
var list = myCollection.GetList(0);             // Get list at index 0
var list = myCollection.GetList("My List");     // Get list with name "My List"

// Selecting value from list
var value = list.PickValue();                   // Select a value from the list
```

### Selecting via PLCollection

The PLCollection class provides a set of methods for selecting values from individual lists or the entire collection.
The collection does not handle the selection logic, it merely provides a convenience layer for working with multiple lists.

The methods are named after the corresponding methods in the ProbabilityList class. 
However, since some of the Probability List methods perform a check whether a value was successfully picked, the PLCollection methods return  boolean value indicating whether the value was picked.

```csharp {{ title: 'Selecting values via PLCollection' }}
var result = myCollection.PickValueFrom(0, out var value);
```
