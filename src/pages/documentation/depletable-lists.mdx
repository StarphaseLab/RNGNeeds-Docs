# Depletable Lists

Depletable Lists are a powerful feature that allows items to have limited availability. By setting the maximum and available units for each item, you can unlock a wide range of possibilities for your game mechanics. Depletable items can be utilized in various ways, such as ensuring unique selections for game rewards or managing multiple instances of the same item, like in card decks or loot tables. {{ className: 'lead' }}

---

## What is a Depletable List?

Simply put, a Depletable List enables the **management of items with limited availability**.

Imagine a scenario where you have a card deck that may contain multiple copies of the same card. In standard RNGNeeds usage, identical cards would be represented by multiple identical entries of the same item. With Depletable Lists, however, the card is represented by a single item with **multiple units**.

When values are picked (cards are drawn) from such a list, the units are **consumed** one by one with each pick, until they reach zero and the item is considered **depleted**, i.e., no longer selectable. Essentially, the card appears to no longer exist in the deck.

Another common scenario is the selection of distinct values only, such as choosing unique game rewards from a pool. With Depletable Lists, this is incredibly easy to achieve by simply setting the list to Depletable and assigning each item a single unit (`1`).

Usages:
- resource collection - ore mining - iron deposit always drops iron ore or stone, has limited precious gems with low probability
- random dungeon generation - random rooms, but only limited amount of treasure rooms (or other type?)
- bag of goods - pick one by one at random
- random quiz questions - ensure they dont repeat

Setting a `ProbabilityList` as **depletable** allows selections to consume units of individual items, assuming they are also set as **depletable**. 
In other words, the list can mix depletable and non-depletable items, and will only consume units of depletable items if the list itself is depletable.

### Setting Probability List as Depletable

By default, Probability Lists are created as **not depletable**, you can think of them as having *infinite units*. 
While this is a default behavior providing the standard usage of RNGNeeds, switching a list between depletable and infinite is very easy.

1. **Activate Advanced Drawer Options Level**: Navigate to the
<a href={PreferencesPage.Link + "#preferences-window"}>{PreferencesPage.Title}</a> 
window and switch Drawer Options Level to **Advanced**. Activating this global setting will reveal advanced features across all your Probability List inspectors.

2. Open the **PICK** section of the drawer and click the **Depletable** button.

Picking values from Depletable Lists consume the units of items which are also marked as depletable. Items with zero available units are considered as depleted and will no longer be selectable until their units are **Refilled**. 
However, items that are **not depletable** will not have their units consumed and will be infinite.

### Depletable Items

On the other hand, by default, Probability Items are created as depletable with `1` available and `1` maximum unit. However, this does not come into play until the list itself is marked as depletable as well.
This allows game designers to switch the depletable states of their lists without losing the depletable settings of each item. Individual items' settings also allow for mixing depletable and infinite items within the lists.

<Note>
    Note that any `ProbabilityItem` created before introduction of Depletable Lists feature (in version 0.9.7) will not be depletable by default and will have its units and maximum units set to `0`. 
    These items will have to be manually setup, however, both the Probability List drawer and API offer convenient ways to set these properties for all items in the list.
</Note>

### Units and Max Units

Each item in the list can be assigned its available and maximum units:
- `Units` - the current available units - number of times the item can be picked. Each pick will consume one unit.
- `MaxUnits` - the maximum units the item can have - this value is utilized when refilling the item or list - available units will be set to the maximum.

## Selection Logic
Whenever a depletable item is picked during selection, its units are lowered by `1` until they reach zero and the item is considered as depleted.

If some of the items in the list are non-depletable (ie. infinite), the selection continues as if only these items were present, ignoring any **disabled** or **depleted** items.
