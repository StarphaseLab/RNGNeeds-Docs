# ドキュメント概要

RNGNeedsのドキュメントセクションへようこそ！このページでは、プラグインの機能とプロジェクトへの効果的な活用方法について、包括的な理解を提供することを目的としています。

ここでは、RNGNeedsの詳細に踏み込み、基本的なコンセプトを探りながら、各機能のポイントをわかりやすく解説します。ドキュメントは、RNGNeedsの各側面に対応した複数のセクションに分かれています。

- <a href={TerminologyPage.Link}>{TerminologyPage.Title}</a> - RNGNeedsで使用される用語とコンセプトを学びましょう。これらをしっかり理解することで、ドキュメント全体やプラグイン自体のナビゲートがスムーズになります。
- <a href={DesigningAListPage.Link}>{DesigningAListPage.Title}</a> - RNGNeedsの中核である Probability List の作成と管理方法を学びましょう。
- <a href={SelectingValuesPage.Link}>{SelectingValuesPage.Title}</a> - RNGNeedsで利用可能なさまざまな選択方法と、その効果的な使い方を理解しましょう。
- <a href={DepletableListsPage.Link}>{DepletableListsPage.Title}</a> - Depletable List を使ってアイテムの可用性を管理し、プロジェクト内でユニークな選択を確保する方法を探りましょう。
- <a href={RepeatPreventionPage.Link}>{RepeatPreventionPage.Title}</a> - RNGNeedsが Probability List 内で同じアイテムの連続選択を回避する仕組みを確認しましょう。
- <a href={ProbabilityInfluencePage.Link}>{ProbabilityInfluencePage.Title}</a> - RNGNeedsのInfluence Providerを使用して、外部要因に基づいて確率を動的に変更する方法を探りましょう。
- <a href={TestingOutcomesPage.Link}>{TestingOutcomesPage.Title}</a> - Inspectorで設定の結果をテストし、さまざまなバリエーションを評価する方法を学びましょう。
- <a href={SeedingOptionsPage.Link}>{SeedingOptionsPage.Title}</a> - RNGNeedsのシーディングオプションを探るか、独自のSeed Providerを使用する方法を学びましょう。
- <a href={PickHistoryPage.Link}>{PickHistoryPage.Title}</a> - RNGNeedsが各リストの過去のアイテム選択を追跡する仕組みと、決定論的な確率挙動を模倣するための履歴の活用方法を理解しましょう。
- <a href={NestingListsPage.Link}>{NestingListsPage.Title}</a> - 複数の Probability List を他のコレクション内にネストすることで、整理と機能性を向上させるメリットを探りましょう。
- <a href={CustomizingListsPage.Link}>{CustomizingListsPage.Title}</a> - Probability List で利用可能なカスタマイズオプション（ビジュアルのカスタマイズや機能的な調整を含む）を深掘りしましょう。
