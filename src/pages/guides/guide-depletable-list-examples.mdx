## Resource Collection

The well-known iron vein in any game world is a valuable resource for players. Often, iron veins are set up to provide iron ore or stone when mined, with a chance for precious gems.
This scenario can be easily replicated using Depletable Lists, with perfect control over the availability of each resource type.
