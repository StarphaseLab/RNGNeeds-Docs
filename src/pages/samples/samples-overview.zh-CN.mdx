## 导入示例

由于 RNGNeeds 以包的形式发布，它不会出现在 Assets 文件夹中，而是位于 Packages 文件夹内。这种设计可使您的项目保持整洁有序。但是，示例需要单独导入。操作步骤如下：

**第一步：打开 Package Manager**

在 Unity 中，导航至 **Window &raquo; Package Manager**。这将打开 Package Manager 窗口，您可以通过该工具管理和安装项目中的各种 Unity 包。

<ImageX className="w-full h-auto" src={installingSamplesPackageManager} alt="Package Manager Window" width="1000"/>

**第二步：找到 RNGNeeds**

在 Package Manager 窗口中，在"In Project"分区下找到 RNGNeeds。

**第三步：导入示例**

点击 RNGNeeds 旁边的箭头展开详细信息，您会看到一个"Import Samples"按钮。点击此按钮即可将示例导入您的项目。

**第四步：在 Assets 文件夹中找到示例**

示例导入完成后，您可以在项目的 Assets 文件夹中找到它们。现在可以随意探索和试验这些示例了。

<ImageX className="w-full h-auto" src={installingSamplesAssetsFolder} alt="Samples in Assets Folder" width="1000"/>

<Note>
    **升级材质**

    将示例导入 URP 或 HDRP 项目时，材质可能会显示为粉红色，需要进行转换。这是因为 RNGNeeds 使用内置渲染管线发布。

    **升级到 URP** - 使用 *Render Pipeline Converter*，参照
    <a href="https://docs.unity3d.com/Packages/com.unity.render-pipelines.universal@16.0/manual/features/rp-converter.html" target="_blank" rel="noopener noreferrer">此指南。</a>

    **升级到 HDRP** - 请参照
    <a href="https://docs.unity3d.com/Packages/com.unity.render-pipelines.high-definition@16.0/manual/Upgrading-To-HDRP.html" target="_blank" rel="noopener noreferrer">此处</a>提供的指南。

</Note>
