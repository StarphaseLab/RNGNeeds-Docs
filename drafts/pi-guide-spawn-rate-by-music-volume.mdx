## Spawn Rate by Music Volume

Through this guide we will explore how we would create a fun mechanic where the spawn rate of monsters increases with the music volume.
Later we will look at how **Inverted Influence** can be utilized to further boost the odds.

### Creating a Simple Monster Spawner

First, we will need a simple way to control the spawn rate, while making it based on probability.

```csharp {{ title: 'Simple Monster Spawner'}}
public class MonsterSpawner : MonoBehaviour
{
    public ProbabilityList<bool> shouldSpawnMonster;

    private void Start()
    {
        InvokeRepeating(nameof(SpawnMonster), 1f, 1f);
    }

    public void SpawnMonster()
    {
        if (shouldSpawnMonster.PickValue())
        {
            // Spawn Monster
        }
    }
}
```

This script will handle the spawning by picking value from a ProbabilityList of type `bool`.
The list is named clearly as a question `shouldSpawnMonster` to indicate it's true/false nature.
One value will be picked every second by calling the `SpawnMonster` method. If `true` is returned, a monster will be spawned.

Attach this component to a GameObject and add two values - **True** and **False**.

<ImageX className="w-full h-auto" src={probabilityInfluenceSpawnByMusicMonsterSpawner} alt="Probability Influence - Spawn by Music - Monster Spawner" width="1000"/>

Setting the True value of the list to 30% will spawn one monster roughly every three seconds.

### Creating the Influence Provider

Now we need a way of feeding the music volume data into our Probability List.

```csharp {{ title: 'Simple Audio Manager'}}
using RNGNeeds;
using StarphaseTools.Core;
using UnityEngine;

[CreateAssetMenu(fileName = "Audio Manager", menuName = "Audio Manager")]
public class AudioManager : ScriptableObject, IProbabilityInfluenceProvider
{
    [Range(0f, 1f)]
    public float sfxVolume;
    [Range(0f, 1f)]
    public float musicVolume;

    public float ProbabilityInfluence => musicVolume.Remap(.5f, 1f, 0f, 1f);
    public string InfluenceInfo => $"Rises with music volume over 50%\nCurrent: {musicVolume:P0} = {ProbabilityInfluence:F2} Inf.";
}
```

This simple AudioManager is a `ScriptableObject` that implements the two properties of the  `IProbabilityInfluenceProvider` interface.

- `float ProbabilityInfluence` - The value of `musicVolume` is remapped so that as the volume rises from 50% to 100%, the Influence will grow from 0 to 1.
This also means that there will never be negative influence.

- `string InfluenceInfo` - the logic of the calculation is communicated to the game designer and will display in the inspector

<ImageX className="w-full h-auto" src={probabilityInfluenceSpawnByMusicAudioManager} alt="Probability Influence - Spawn by Music - Audio Manager" width="1000"/>

Once we create the AudioManager ScriptableObject in Unity Editor, we can assign this Influence Provider to the MonsterSpawner's ProbabilityList.
Expand the Influence Options of the True value in the list and drag the AudioManager into the object field.
