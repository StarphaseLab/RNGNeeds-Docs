# Contributing to RNGNeeds Documentation

Thanks for your interest in improving the RNGNeeds docs! 🎲

## How to Contribute

1. **Fork** this repository
2. Create a branch from `dev` (not `deploy`)
3. Make your changes
4. Open a **Pull Request targeting the `dev` branch**

> ⚠️ All pull requests must target the `dev` branch. PRs to `deploy` will be closed.

The `deploy` branch is production — we merge `dev → deploy` when a release is ready.

## What You Can Help With

- Fix typos or unclear explanations
- Improve code examples
- Suggest new guides or samples
- Translation improvements (Chinese, Japanese)

## Local Development

```bash
npm install
npm run dev
```

The site runs at `http://localhost:3000`.
